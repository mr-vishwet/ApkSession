adrdrounds
Android roundsbuild, walk, mask, share

One round, one device.

Each row is a session folder. Open it to upload the build and spec, run the walk, watch the screen while it goes, cut the session into sections and export the masked video. Everything stays inside sessions/<id>/.

How a round goes

  1. Upload the APK under test, up to 200 MB. It lands in the session; nothing installs until you start the run.
  2. Choose the scope. Focused requires a spec and tests only the steps it names. Full app treats the spec as optional: spec steps first, then every route the source scan found.
  3. Upload the spec as .md, .txt, .xml or .pdf when you have one. It is the source of the cases, and full scope also merges the routes it never mentions.
  4. Start the run. It installs the build, cold-starts it, replays the walk while the screen is recorded, masks the branding, burns in the captions, writes the report and builds the bundle.
  5. Watch it live from the console or from a live link you send. The masked master and one clip per chapter appear as the render finishes.
  6. Share the masked result. Only the rendered video, section cuts and report leave the session. The raw capture is unmasked.
